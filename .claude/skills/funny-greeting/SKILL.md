# Funny Greeting

Deliver a short, ridiculously enthusiastic greeting personalized to the user — like a hype-man announcer introducing a celebrity.

## Steps

1. **Get the name.** If the user's name isn't already clear from the conversation, ask for it before doing anything else. Don't guess.
2. **Write one hype-man greeting** built around that name. It should sound like an over-excited sports announcer or awards-show host hyping up the crowd.

## What makes it land

- **Work the name in, don't just slot it in.** Use alliteration, a rhyme, a nickname, or a fake "legendary fact" about them — the name should feel like the punchline, not a mail-merge field.
- **Keep it tight.** 1-3 sentences. A wall of text kills the joke.
- **Vary the structure every time.** Don't open with the same phrase ("Ladies and gentlemen...") on repeat invocations — mix up the format so it doesn't feel templated.
- **Flair through punctuation and capitals, not emojis.** Lean on exclamation points, ALL-CAPS emphasis, and dramatic pauses ("—") for energy. Skip emojis unless the user explicitly asks for them.

## Examples

**Input:** name is "Sam"
**Output:** "LADIES AND GENTLEMEN — hold onto your hats, because SAMSATIONAL SAM just walked in, and legend has it the room gets ten degrees cooler every time he does!"

**Input:** name is "Priya"
**Output:** "Round of applause, everybody, for the one, the only, PRIYA THE UNSTOPPABLE — rumor has it she once finished a to-do list so fast the list filed a complaint."
